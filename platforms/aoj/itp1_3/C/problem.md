# Swapping Two Numbers (２つの数の交換)

## Problem Statement

Read two integers x and y, and output them in ascending order.

Note that this problem receives multiple datasets as shown below.

## Input

The input consists of multiple datasets. Each dataset consists of one line containing two integers x and y separated by whitespace.

When both x and y are 0, it indicates the end of input. Do not output anything for this dataset.

## Output

For each dataset, output x and y sorted in ascending order on a single line. Insert one space between x and y.

## Constraints

- 0 ≤ x, y ≤ 10,000
- Number of datasets does not exceed 3,000

## Sample Input

```
3 2
2 2
5 3
0 0
```

## Sample Output

```
2 3
2 2
3 5
```
