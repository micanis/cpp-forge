# Sorting Three Numbers (3つの数の整列)

## Problem Statement

３つの整数を読み込み、それらを値が小さい順に並べて出力するプログラムを作成して下さい。

Read three integers and write a program to output them in ascending order.

## Input

３つの整数が空白で区切られて与えられます。

Three integers are given separated by spaces.

## Output

小さい順に並べ替えた３つの整数を１行に出力して下さい。整数の間に１つの空白を入れて下さい。

Output the three integers sorted in ascending order on a single line. Put one space between the integers.

## Constraints

- 1 ≤ Each of the three integers ≤ 10,000

## Sample Input / Output

### Sample 1
**Input:**
```
3 8 1
```

**Output:**
```
1 3 8
```
