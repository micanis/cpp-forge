# Small, Large, or Equal (大小関係)

## Problem Statement

読み込んだ２つの整数 a, b の大小関係を出力するプログラムを作成して下さい。

(Create a program that reads two integers a and b and outputs their relationship.)

## Input

入力は空白で区切られた２つの整数 a, b から構成されています。

(The input consists of two integers a and b separated by a space.)

## Output

- a より b の方が大きければ、`a < b` と出力して下さい。(If b is greater than a, output `a < b`)
- a より b の方が小さければ、`a > b` と出力して下さい。(If b is smaller than a, output `a > b`)
- a と b が等しければ、`a == b` と出力して下さい。(If a and b are equal, output `a == b`)

## Constraints

- -1,000 ≤ a, b ≤ 1,000

## Sample Input/Output

### Sample 1
Input:
```
1 2
```
Output:
```
a < b
```

### Sample 2
Input:
```
4 3
```
Output:
```
a > b
```

### Sample 3
Input:
```
5 5
```
Output:
```
a == b
```
