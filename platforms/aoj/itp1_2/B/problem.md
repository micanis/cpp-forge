# Range

## Problem Statement
３つの整数a, b, cを読み込み、それらが a < b < cの条件を満たすならば"Yes"を、満たさないならば"No"を出力するプログラムを作成して下さい。

(Read three integers a, b, c and output "Yes" if they satisfy the condition a < b < c, otherwise output "No".)

## Input
３つの整数が空白で区切られて与えられます。

(Three integers are given separated by spaces.)

## Output
YesまたはNoを１行に出力して下さい。

(Output "Yes" or "No" on a single line.)

## Constraints
- 0 ≤ a, b, c ≤ 100

## Sample Input/Output

### Sample 1
**Input:**
```
1 3 8
```

**Output:**
```
Yes
```

### Sample 2
**Input:**
```
3 8 1
```

**Output:**
```
No
```
