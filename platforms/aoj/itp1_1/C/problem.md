# Rectangle

## Problem Statement

長方形の面積と周の長さ

たて a cm よこ b cm の長方形の面積と周の長さを求めるプログラムを作成して下さい。

(Find the area and perimeter of a rectangle with height a cm and width b cm.)

## Input

a と b が１つの空白で区切られて与えられます。

(a and b are given separated by a single space.)

## Output

面積と周の長さを１つの空白で区切って１行に出力して下さい。

(Output the area and perimeter separated by a single space on one line.)

## Constraints

- 1 ≤ a, b ≤ 100

## Examples

### Sample Input 1
```
3 5
```

### Sample Output 1
```
15 16
```

### Explanation
For a rectangle with height 3 cm and width 5 cm:
- Area = 3 × 5 = 15
- Perimeter = 2 × (3 + 5) = 16
