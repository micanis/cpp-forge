# Watch

## Problem Statement

Given time S in seconds, convert and output it in h:m:s format. Here, h is hours, m is minutes less than 60, and s is seconds less than 60.

## Input

S is given on one line.

## Output

Output h, m, s separated by : (colon) on one line. If a number is single digit, you don't need to pad with 0 to make it 2 digits.

## Constraints

- 0 ≤ S < 86400

## Sample Input and Output

| Input | Output |
|-------|--------|
| 46979 | 13:2:59 |
